# Workflow: Standard Problem Solving

Use for substantive decisions, recurring problems and improvement opportunities.

## Step 1 — Frame
Use `templates/intake_and_problem_framing.md`.
Confirm the problem, outcome, context and constraints.

## Step 2 — Explore
Use `templates/divergent_idea_generation.md`.
Work through all six divergent lenses. Do not score ideas yet.

## Step 3 — Set criteria
Agree the evaluation criteria and any non-negotiable constraints.

## Step 4 — Evaluate
Use `templates/option_evaluation.md`.
Apply all six convergent lenses to shortlisted options.

## Step 5 — Connect
Use the integration patterns in `references/lateral_integration.md`.

## Step 6 — Decide
Select a decision status from `references/decision_quality.md`.

## Step 7 — Test
Use `templates/experiment_and_learning.md` if uncertainty can be reduced through a test.

## Step 8 — Report
Use `templates/final_analysis_report.md`.

## Pause points
Pause for user confirmation when:
- The problem framing is materially uncertain.
- A value judgement or trade-off belongs to the user.
- A critical assumption is unresolved.
- A decision is consequential or hard to reverse.
