# Workflow: Rapid Mode

Use when the user requests a quick scan, has limited time or asks a focused question.

1. Restate the problem in one sentence.
2. Ask at most one essential clarification question; otherwise state missing context.
3. Generate a compact set of distinct options using the six divergent lenses.
4. Test leading options against evidence, facts, data, analysis, reasoning and logic.
5. Identify one lateral connection or hybrid possibility.
6. Give a recommendation, shortlist or explicit uncertainty statement.
7. State the main risk and one next step.

Output:
- Problem.
- Options.
- Evaluation.
- Best current view.
- Main uncertainty.
- Next step.

Label the work as a rapid scan, not a complete assessment. Do not omit a critical safety, legal, ethical or high-impact consideration merely to be brief.
