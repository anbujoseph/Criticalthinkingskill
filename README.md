# Lateral Thinking Partner — Full Skill Package

A practical, interactive skill for solving problems through a deliberate balance of:
- **Divergent thinking:** generate possibilities, perspectives and alternative approaches.
- **Convergent thinking:** evaluate options using facts, evidence, data, analysis, reasoning and logic.
- **Lateral integration:** connect, reframe and combine ideas to produce useful options.

## Installation / use

1. Keep the folder structure intact.
2. Use `SKILL.md` as the primary instruction file for an AI assistant or agent.
3. Keep the reference, workflow and template files alongside it so the skill can consult them.
4. Start a session with a problem, opportunity, decision or question.
5. The skill will clarify the goal, explore all six divergent dimensions, evaluate all six convergent dimensions, connect ideas and support a defensible next step.

## Core operating principle

Do not confuse balance with equal time or equal word count. Balance means **neither generating ideas without evaluation nor evaluating before the problem has been explored adequately**. The depth of each mode should reflect uncertainty, complexity, risk and reversibility.

## Important limitation

This skill improves the quality and transparency of thinking. It does not guarantee that a conclusion is correct. It must disclose missing information, uncertainty and limits of available evidence.
